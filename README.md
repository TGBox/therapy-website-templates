# therapy-website-templates

A compilation of different physiotherapist websites using modern webdesign patterns and fake, but believable data.

## Tech-Stack

- **Runtime:** Node.js (>= 22)
- **Sprache:** TypeScript (Strict Mode)
- **Test-Runner:** Vitest
- **CI/CD:** GitHub Actions

## Setup & Ausführung

```bash
npm install
npm run dev     # Hot-Reload Dev Mode
npm run test    # Tests ausführen
npm run build   # Production Build
```

Die Live Preview ist dann erreichbar unter [localhost:3000](http://localhost:3000/index.html).
